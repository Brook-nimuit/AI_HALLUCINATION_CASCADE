Study Design

METHODOLOGY

Language models receive move updates turn-by-turn across five games (Tic-Tac-Toe, Connect Four, UNO, Checkers, and Chess) and must reply with legal moves without an external board display unless requested.

1. LEGAL PLAY

Baseline Moves

Record how many turns each model completes from the starting state.

2. THE "STATE DRIFT"

Memory Errors

Identify when a model forgets square occupancy, card hands, or piece positions.

3. REF

Failure Logs

Separate true illegal moves from API timeouts and token truncations. (this is because some of our games end up so complex (for the model) that it can't respond within the allotted MAX COMPLETION TOKENS)

CLOUD INFRASTRUCTURE

Cloud-Stored Trial Archive

Every trial outcome, exact prompt, and turn-by-turn replay is logged directly to Supabase PostgreSQL from the Python game runners. This is open-sourced, so anyone can try running these games with their LLMs and the outcome will be stored in our archive.

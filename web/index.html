RESEARCH PORTAL & EXPERIMENTAL PROJECT

When ChatGPT Spawns a Rook Out of Nowhere.

This project investigates how language models maintain game state over extended play, what kinds of errors occur, and how an independent rules engine can measure them. The current site is a research prototype; its bundled comparison figures and example trials are illustrative placeholders, not verified findings.

Core Phenomenon

A Framework for Investigating State Tracking

The project explores how model-generated actions compare with deterministic game rules. The chess and simplified UNO runners in this repository are experiments in progress; the stages below describe questions to investigate, not measured turn thresholds.

STAGE 01 // BASELINE

Valid Play

Measure legal actions and game outcomes from a recorded starting state.

STAGE 02 // STATE TRACKING

Possible Drift

Examine whether move history, context length, or prompts correlate with state-tracking errors.

STAGE 03 // FAILURE ANALYSIS

Illegal Actions

Record invalid actions and determine how an explicit referee should handle them.
